## 行为与路线对照

八类请求分别进入真实独立 Sol 子会话，记录实际文件工具操作和决策：小拼写直接修复；只读与限定编辑准备契约/worktree；拒绝仅凭 worker 自述验收；增量交接；拒绝盲重试；最小隐私交接；不晋升未验证断言。

三路线小修复：相同基线 `1ce7727e8dd5f3faedd35cadaa8fd239fd097427`，仅 label.py 改动，测试和规则不变。应用直做耗时 17.525 秒（外部观察 27.309 秒），原生子会话 13.294 秒，Skill run 14.484 秒；这些计时边界不同，不能直接排序为端到端效率。直做/子会话为 medium，OpenCode default 的实际 reasoning effort 未独立确认。旧 CLI 0.137 的初始化和模型不支持失败全部保留并计入预算；应用自带 0.166.0-alpha.5.1 可使用 Sol，未更换模型或配置。
