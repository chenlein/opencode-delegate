## 本轮发现和修复

### R01 / P2：发行 ZIP 漏掉嵌套验收证据

原 `tools/build_release.py` 只取 docs 顶层文件。实际构建 ZIP 后确认没有 `docs/evidence/mac-rc8/`，因此已打包的验收裁定链接到不存在的附件。这是发行物可复核性缺陷，不是 GitHub 已发布证据缺失。

修复：只添加 `SHA256SUMS.txt` 明确列入并逐项校验的嵌套证据，拒绝变更文件、未审文件、路径逃逸、重复条目和符号链接，不把 docs 整树无审核递归打包。保持实际目录规范化，兼容 macOS 的合法根路径别名。

新增六项回归：发行 ZIP 对全部证据逐字节核对、篡改拒绝、额外运行日志拒绝、父目录逃逸拒绝、子目录符号链接拒绝、合法根别名允许。加入五平台 CI。原 33 个安装输入及 MANIFEST 不变。

### R02 / P3：两个测量入口仅运行 help 也污染安装包

`benchmark_repository.py` 和 `benchmark_snapshot.py` 在未设置 PYTHONDONTWRITEBYTECODE 时导入运行时，生成 Skill 目录下的 pyc，导致安装器完整性校验随后拒绝该目录。扩展已有隔离安装回归后真实 FAIL，修复后 PASS；没有忽略额外文件或放宽安装器校验。

修复：两个测量入口在导入项目模块前禁写字节码。已有安装测试扩展覆盖两种原生探测、两种测量和发布入口。测试夹具隔离，不读取或修改用户工程。
